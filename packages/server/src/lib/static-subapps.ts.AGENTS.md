# static-subapps.ts — index

The static sub-app surfaces, as ONE list. Exports `MOBILE_PREFIX` (`"/mobile"`), `LINKS_PREFIX` (`"/links"`), `SUB_APP_PREFIXES`. Lives in `lib/` because `auth/localhost-guard.ts` builds `GUARD_JURISDICTION_PREFIXES` from `SUB_APP_PREFIXES` and deliberately keeps itself free of `routes/` imports; one neutral module imported by both breaks no cycle. Purpose: the served set and the guarded set must be the same list, so a sub-app cannot be added to one and forgotten by the other. That omission happened — `/links/` shipped outside the guard while its HTML carried the tailnet, host LAN, Brain/sandbox names and service ports. Prefixes are matched BARE by the guard (not slash-anchored like `/api/`) so the slashless redirect entries are claimed too. See change: add-same-origin-mobile-poc, guard-static-subapps.
